🔧 Simulador de Dimensionamento de Geradores – Infinita Geradores

Ferramenta prática para estimativa rápida de potência de geradores.

Permite inserir cargas, converter unidades (kW / CV / HP) e calcular automaticamente o kW total e kVA estimado.

Desenvolvido para uso técnico em campo, estudos preliminares e apoio a orçamentos.

⚙️ Funcionalidades
Inserção de múltiplas cargas
Conversão automática de unidades
Cálculo de kW total e kVA estimado
Interface simples e otimizada para mobile
🔒 Versão Gratuita
Limite de até 5 cargas
🚀 Versão Completa
